## Selected Projects

### Dental RAG Agent <span style="font-size: 0.7em; font-style: italic; color: #666;">Personal Project</span>

Built an end-to-end retrieval-augmented generation (RAG) system for dental reference materials, combining document ingestion, metadata extraction, semantic chunking, vector embeddings, and ChromaDB-based retrieval to provide context-aware question answering across structured and unstructured documents. Integrated an LLM to generate grounded responses from retrieved context, with support for document summarization, streaming responses, and citation tracking to improve answer transparency and traceability.

**Tools:** Python, Langchain, ChromaDB, HuggingFace, GROQ API

### CLIP Image Captioning <span style="font-size: 0.7em; font-style: italic; color: #666;">Personal/Startup Project</span>

Developed an AI-powered image captioning system that bridges computer vision and natural language generation by using CLIP to encode visual information and GPT-2 to generate descriptive captions. Trained the multimodal pipeline on over 300K image-text pairs and optimized the preprocessing workflow to reduce processing time by 25%, ultimately achieving a ROUGE-L score of 0.51 on the evaluation set.

**Tools:** Python, Git, HuggingFace, PyTorch, Pandas/Numpy
